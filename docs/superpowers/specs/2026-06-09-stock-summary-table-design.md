# 个股汇总行情表设计

## 目标

参考用户提供的行情表截图，将“个股汇总”改造成高密度、可排序的交易数据表，便于快速比较当日强弱、入选成本和盈亏表现。

## 表格结构

列顺序固定为：

1. 序号
2. 代码
3. 名称
4. 入选模式
5. 入选板块
6. 涨幅
7. 入选价格
8. 入选涨幅
9. 今日盈亏

默认按“涨幅”从高到低展示。汇总数据按股票代码去重，同一股票只保留置信度最高的一条信号。

## 数据口径

- 涨幅：读取 `score_breakdown["涨跌幅"]`，没有真实值时显示 `-`。
- 入选价格：读取 `signal_price`。
- 入选涨幅：优先读取 `floating_pnl`；否则在 `current_price` 和 `signal_price` 都有效时计算。
- 今日盈亏：读取 `actual_pnl`；没有真实值时显示 `-`。
- 入选板块：读取 `sector_name`；为空时显示 `未分类`。

## 视觉规则

- 保持现有黑灰色交易终端风格。
- 股票代码和名称使用亮黄色，提高扫描效率。
- 入选模式使用现有策略标签颜色。
- 板块使用蓝色。
- A 股涨跌遵循红涨绿跌，正数带 `+`。
- 表头和数值列支持排序，行高保持紧凑。

## 验证

- 静态契约检查列结构、去重和排序逻辑。
- `npm run build` 验证 TypeScript 和生产构建。
- 浏览器检查桌面宽度下表头、数字和行内容无重叠。
