# AI 交易大师 P0 核心模块 PRD

> 项目：ai-trader | 版本：v1.0 | 日期：2026-06-01 | 作者：许清楚（Xu）

---

## 1. 产品目标

通过实现**因子计算引擎、信号生成系统、用户系统**三大模块，让 AI 交易大师从"可看"升级为"可用"——用户可注册登录、查看真实因子数据、收到策略驱动的交易信号并执行操作。

---

## 2. 用户故事

1. **As a** 散户投资者，**I want** 用手机号注册登录，**so that** 我的自选股、信号记录、会员权益等数据能跨设备持久化。
2. **As a** 策略订阅者，**I want** 查看策略背后的 7 大因子实时状态和变动趋势，**so that** 我能判断策略当前是否适合入场。
3. **As a** 择时交易者，**I want** 系统基于因子数据自动生成买卖信号并标注置信度，**so that** 我能快速决策而非手动分析所有指标。
4. **As a** 实盘执行者，**I want** 对信号执行"买入/忽略"操作并设置止损止盈预警，**so that** 我能按纪律交易并及时止盈止损。
5. **As a** Free 用户，**I want** 看到哪些策略/信号属于 Pro/Flagship 权限，**so that** 我能决定是否升级。

## 4. 模块说明

### 4.1 因子计算引擎

**职责**：从行情数据中提取 7 大因子，供信号生成和前端展示使用。

| 因子标签 | 计算逻辑概要 | 输入数据 | 输出 |
|----------|-------------|---------|------|
| 估值优势 | PE/PB 分位数（近 250 日）越低分越高 | 个股日 K、财务指标 | 0-100 分值 |
| 涨势动力 | MA5 > MA20 > MA60 得分递增 + MACD 金叉加分 | 日 K（MA/MACD） | 0-100 分值 |
| 资金热度 | 主力净流入占比 + 换手率加权 | 资金流向、换手率 | 0-100 分值 |
| 反弹潜力 | 距近 60 日高点回撤幅度，回撤越深潜力越高 | 日 K 高点 | 0-100 分值 |
| 市场温度 | 全市场上涨家数占比 + 涨停家数占比 | 全市场行情统计 | 0-100 分值 |
| 震荡程度 | ATR(14) / Close 标准化 + 布林带宽度 | 日 K（ATR/布林带） | 0-100 分值 |
| 突破强度 | 收盘价突破布林上轨 / 前高 + 成交量放大倍数 | 日 K + 成交量 | 0-100 分值 |

**计算频率**：每个交易日收盘后批量计算（15:30 触发），盘中实时因子每 5 分钟增量更新。

**状态判定规则**：
- `normal`：value ≥ 40 且 |change| ≤ 5
- `warning`：value < 40 或 |change| > 5
- `danger`：value < 20 或 |change| > 10

**输入**：AKShare 行情数据（已接入）
**输出**：`FactorState[]`，通过 `GET /api/strategies/:id/factors` 返回

### 4.2 信号生成系统

**职责**：基于因子数据 + 策略规则，自动生成买卖信号。

**信号生成规则**：

| 策略类型 | 买入信号触发条件 | 卖出信号触发条件 |
|---------|----------------|----------------|
| 低吸 | 估值优势 ≥ 70 且 反弹潜力 ≥ 60 且 市场温度 < 40 | 浮盈 ≥ take_profit_pct 或 浮亏 ≥ stop_loss_pct |
| 趋势 | 涨势动力 ≥ 75 且 突破强度 ≥ 60 | 涨势动力 < 30 或 浮亏 ≥ stop_loss_pct |
| 突破 | 突破强度 ≥ 80 且 资金热度 ≥ 60 | 突破强度 < 20 或 浮亏 ≥ stop_loss_pct |
| 均值回归 | 震荡程度 ≥ 65 且 估值优势 ≥ 50 | 价格回归均值 ±2% 或 浮亏 ≥ stop_loss_pct |

**置信度计算**（0-100）：
```
confidence = w1 * 主因子得分 + w2 * 辅因子得分 + w3 * 资金热度 + w4 * 市场温度
```
- 主因子权重 0.4，辅因子 0.25，资金热度 0.2，市场温度 0.15
- 各因子得分归一化到 0-100 后加权求和

**止损止盈逻辑**：
- 买入信号默认止损：signal_price × (1 - stop_loss_pct)，默认 stop_loss_pct = 5%
- 买入信号默认止盈：signal_price × (1 + take_profit_pct)，默认 take_profit_pct = 10%
- 用户可通过 `PUT /api/signals/:id/alert` 自定义止损止盈价

**预警状态转换**：
```
safe → warning: 浮亏 ≥ stop_loss_pct × 70% 或 浮盈 ≥ take_profit_pct × 70%
warning → stop_loss: 浮亏 ≥ stop_loss_pct
warning → take_profit: 浮盈 ≥ take_profit_pct
```

**信号生命周期**：`pending → executed/ignored/expired → closed`
- `pending`：新生成，待用户确认
- `executed`：用户点击买入
- `ignored`：用户主动忽略
- `expired`：24h 未确认自动过期
- `closed`：已卖出（SELL 信号触发或止损止盈）

### 4.3 用户系统

**认证方式**：手机号 + 短信验证码
- `POST /api/user/send-code`：发送验证码（MVP 用 mock，固定返回 123456）
- `POST /api/user/register`：注册（phone + code + nickname）
- `POST /api/user/login`：登录（phone + code），返回 JWT token + user
- `POST /api/user/refresh-token`：刷新 token

**Token 设计**：
- Access Token：JWT，有效期 2h，payload 含 { user_id, phone, plan, exp }
- Refresh Token：有效期 30d，用于无感续期
- 前端已有 Bearer 注入拦截器 + 401 跳转逻辑，后端需实现校验中间件

**会员体系**：

| 等级 | 价格 | 权限 |
|------|------|------|
| free | 免费 | 低吸一号/趋势一号/突破一号/均值回归一号 + 每日 3 条信号 |
| pro | ¥298/月 | 含 pro 策略 + 每日不限信号 + 预警通知 |
| flagship | ¥998/月 | 全部策略 + 旗舰策略 + VIP 因子分析 + 专属信号 |

**权限控制**：
- 策略访问：`required_plan` 字段控制，用户 `plan` 等级 ≥ `required_plan` 可订阅
- 信号可见：Free 用户每日可见信号上限 3 条，Pro/Flagship 不限
- 权限等级：free(0) < pro(1) < flagship(2)，前端 `usePermission` hook 已实现比对逻辑
